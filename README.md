# GTM Radar 🚀

Бекенд-система для автоматизованої аналітики B2B SaaS платформ, моніторингу їх змін (Swipe Files) та GTM-стратегій.

## Опис проекту
Проект призначений для масового збору даних про стартапи з Product Hunt, їх подальшого парсингу та інтелектуальної обробки. Система автоматично знаходить цільові сторінки (прайсинги, фічі, кейси) на сайтах компаній та готує дані для AI-аналізу.

## Основний функціонал
- **PH Scraper:** Збір бази стартапів через Product Hunt GraphQL API.
- **SQLite Database:** Локальне зберігання даних (стартапи, сторінки, снепшоти, інсайти) зі статусами обробки (`unscraped`, `scraped`, `failed`).
- **Playwright Extractor:** Асинхронний парсинг сайтів, збір внутрішніх посилань та обхід базових блокувань.
- **OpenAI Router:** Використання LLM (`gpt-4o-mini`) для класифікації зібраних лінків та знаходження ключових URL-адрес.

## Стек технологій
- Python
- SQLite
- Playwright (Async)
- OpenAI API
- GraphQL
